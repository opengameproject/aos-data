AoS Data
========

Community data files for AoS 4th edition army lists.

## Contents ##

* `*.gst` is the game system file. It holds the core rules, shared units and shared abilities.
* `*.cat` files are the catalogues. Each faction has one catalogue. Most factions also have a `Library` catalogue and one catalogue per Army of Renown.
* `Lores.cat`, `Regiments of Renown.cat` and the `Path to Glory` catalogues hold content that many factions share.

The files use the BattleScribe XML data format.

## Using the data ##

Any app that reads BattleScribe-format data can load these files. Point the app at this repository, or download the files and load them by hand.

## Reporting a problem ##

Open an issue in this repository. Name the faction, the unit or rule, and what is wrong. Check the open issues first, so the same problem is not reported twice.
